# 프로젝트 목표와 지표 체계

지금은 프로토타입 구축이 우선이다. 목표와 north star 정의만 정했고, 하위 지표와 목표값은 프로토타입 뒤에 정한다. 경위와 승인 내용은 #10에 있다.

## 목표

한국 사용자가 친구·지인과 방을 만들어 바로 한 판을 칠 수 있는, 실제로 쓸 만한 웹 멀티플레이 포커를 만든다. 만들고 운영하는 과정에서 얻은 인사이트를 기록해 다음 프로젝트를 계획하는 근거로 쓴다.

## North star 지표

**주간 완료 멀티 핸드 수**: 지난 7일 동안 팟이 승자에게 지급된 핸드 중 카드를 받은 계정이 2개 이상인 핸드 수.

- 완료: 팟이 승자에게 지급된 핸드(쇼다운 또는 한 명 빼고 모두 폴드). 중간에 방이 깨져 끝나지 않은 핸드는 세지 않는다.
- AI agent 계정만 참여한 핸드도 센다.
- 핸드마다 사람 계정 수와 AI agent 계정 수를 기록한다. 나중에 사람이 참여한 핸드만 따로 볼 수 있게 하기 위해서다.
- test·debug 표시가 있는 계정은 지표에서 분리한다.

목표값은 정하지 않았다.
